# Food Detector

This app is designed to detect 21 different types of food. It is powered by an AI deep-learning CNN model using PyTorch. It has been trained on a wide range of food images and achieves 80.4% accuracy in its detection.

## How to Use the App

Send an RGB picture of any resolution from any camera to your PC.

There are two ways to run the application:

### Method 1: Using the Source Files

Make sure the following files are available:

1. FoodGraphics.ipynb — The notebook required to run the application.
2. FoodModel.ipynb — The notebook containing the model development process.
3. foodModel.pt — The trained deep-learning model.

Place FoodGraphics.ipynb and FoodModel.ipynb in the Sources folder and make sure foodModel.pt is in the appropriate directory.

Important: You must run FoodGraphics.ipynb for the application to work.

### Method 2: Using the Executable (.exe)

Download the application along with all the necessary files.
Make sure the files and folders remain in their original structure.
Locate the .exe file and create a shortcut on your desktop, or run it directly from its folder.

This method does not require you to manually run the Jupyter notebooks.

## Requirements

For the source-code method, make sure Python and PyTorch are installed on your computer, along with the necessary libraries.

If you use the executable version, Python and PyTorch may not need to be installed separately, depending on how the application was packaged.
